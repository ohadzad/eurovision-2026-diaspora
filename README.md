# Eurovision 2026 — Israel Televote vs. Jewish Population

Interactive visual report cross-referencing the public vote for Israel in the Eurovision 2026 Grand Final (16.5.2026) with the size of the Jewish population in each country.

View it live: https://ohadzad.github.io/eurovision-2026-israel-vote/

## What's in the report

- Scatter plot: votes for Israel vs. Jewish population per country (log scale)
- Pearson correlation between Jewish population size and votes given
- The six "12-point" countries — what they have in common
- Big communities that didn't translate to votes (Australia, UK, France)
- Anomalies in both directions (Albania, Finland, Portugal vs. Australia, Croatia)
- Full color-coded data table

## Sources

- Vote totals: Eurovision 2026 Grand Final televote
- Jewish population: DellaPergola / American Jewish Year Book (2020–2024), Jewish Virtual Library
